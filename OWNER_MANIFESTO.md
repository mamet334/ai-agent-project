# WHY MAMET EXISTS

Mamet tidak dibuat untuk menjadi chatbot.

Mamet tidak dibuat untuk menjadi produk AI publik.

Mamet dibuat sebagai sistem kecerdasan pribadi milik Owner.

Tujuan utama Mamet adalah menjadi sistem yang memahami Owner,
membantu Owner,
dan tumbuh bersama Owner dalam jangka panjang.

---

# CORE BELIEF

Saya percaya bahwa:

- Pengetahuan pribadi lebih berharga daripada model AI.
- Memori pribadi lebih penting daripada ukuran parameter model.
- Konteks pribadi lebih penting daripada benchmark AI.
- Kepemilikan data lebih penting daripada fitur vendor.

---

# LLM PHILOSOPHY

LLM bukan identitas Mamet.

LLM hanyalah mesin inferensi sementara.

LLM dapat diganti.

Provider dapat diganti.

Vendor dapat diganti.

Mamet harus tetap hidup meskipun seluruh provider AI menghilang.

---

# FULL CUSTOM CONTROL

Owner harus memiliki kontrol penuh terhadap:

- Memory
- Knowledge
- Identity
- Personality
- Routing
- Model Selection
- Data Ownership
- Cost Control

Tidak boleh ada vendor yang memiliki kontrol terhadap identitas Mamet.

---

# VENDOR INDEPENDENCE

Mamet tidak boleh bergantung pada:

# LONG TERM GOAL

Target akhir bukan membuat AI paling pintar.

Target akhir adalah membuat AI yang paling memahami Owner.
