# MAMET DESIGN PHILOSOPHY

Version : 1.0
Status  : ACTIVE

---

# 1

Simple beats complex.

Jika dua solusi memiliki hasil sama,
pilih solusi yang lebih sederhana.

---

# 2

Small Kernel.
Large Capability.

Kernel harus kecil.

Capability dapat berkembang tanpa batas.

---

# 3

Capability is optional.

Tidak semua pengguna membutuhkan capability yang sama.

Capability harus dapat ditambahkan dan dilepas.

---

# 4

Everything is replaceable.

Tidak ada komponen yang sakral selain Constitution.

Semua implementasi dapat diganti.

---

# 5

LLM is a capability provider.

LLM bukan pusat sistem.

LLM hanyalah salah satu capability provider.

---

# 6

Memory belongs to Mamet.

Memory tidak boleh dimiliki provider AI.

Memory adalah identitas Mamet.

---

# 7

Knowledge belongs to Workspace.

Knowledge harus terisolasi.

Workspace pertanian tidak boleh mencemari workspace komputer.

Workspace hukum tidak boleh mencemari workspace kesehatan.

---

# 8

Owner decides the brain.

Mamet tidak memilih model.

Owner memilih model.

Mamet hanya menggunakan model yang dipilih Owner.

---

# 9

Architecture before implementation.

Code mengikuti architecture.

Architecture mengikuti Constitution.

---

# 10

Root Cause First.

Jangan memperbaiki gejala.

Perbaiki penyebabnya.

---

# 11

Permanent Solution First.

Lebih baik refactor sekali
daripada menambal sepuluh kali.

---

# 12

Observability is mandatory.

Sistem yang tidak dapat diamati
adalah sistem yang tidak dapat diperbaiki.

---

# 13

Data ownership is mandatory.

Owner harus selalu dapat mengekspor:

- Memory
- Knowledge
- Configuration
- History
- Logs

tanpa ketergantungan vendor.

---

# 14

Offline survival.

Mamet harus memiliki jalur evolusi menuju:

- self hosting
- local database
- local inference
- local memory

meskipun belum diimplementasikan saat ini.

---

# FINAL PRINCIPLE

Build systems.

Not features.
