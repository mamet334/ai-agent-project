      |

      |
      v

      |
      v
  if (!isValid) → HARD STOP
    - return stream SSE dengan pesan BLOCKED (tidak panggil LLM)
    - return JSON response (jika non-stream)
      |
      v  (jika isValid)
  inject gateVerdictText ke fullSystemContext
      |
      v
  LLM dipanggil dengan evidence terdaftar

Rules yang aktif:
  RULE 1: Engineer + totalEvidence=0        → BLOCKED (hard stop, LLM tidak dipanggil)
  RULE 2: Engineer + brain=0 tapi rag/mem>0 → WARNING (lanjut, instruksi ketat)
  RULE 3: Non-Engineer + rag=0 + mem=0     → WARNING (boleh jawab umum)
  DEFAULT: PASSED
