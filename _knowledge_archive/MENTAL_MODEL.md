# OWNER VIEW

Owner
↓
Mamet OS Ecosystem
↓
Capabilities
↓
LLM Providers
↓

---

# LLM MODEL

LLM = CPU pinjaman

LLM digunakan untuk:

- reasoning
- summarization
- generation
- extraction
- planning

LLM tidak menyimpan identitas Mamet.

---

# MEMORY MODEL

Memory = pengalaman hidup Mamet

Memory adalah:

- fakta pengguna
- preferensi pengguna
- keputusan masa lalu
- pengalaman interaksi

Memory adalah identitas.

---

# KNOWLEDGE MODEL

Knowledge = perpustakaan Mamet

Knowledge bersifat:

- spesifik domain
- spesifik workspace
- dapat dipindahkan
- dapat diekspor

---

# RAG MODEL

RAG bukan memori.

RAG adalah sumber referensi.

RAG dapat dihapus.

Memori tidak boleh hilang.

---

# ENGINEER MODEL

Engineer adalah bengkel internal Mamet.

Tugas Engineer:

- audit
- debugging
- refactoring
- architecture review
- verification
- self improvement

Engineer menjaga kesehatan sistem.

---

# ASSISTANT MODEL

Assistant adalah pendamping pribadi Owner.

Assistant berinteraksi dengan dunia luar.

Assistant menggunakan:

- Memory
- Knowledge
- Context
- Capability

untuk membantu Owner.

---

# KERNEL MODEL

Kernel hanya menyediakan:

- lifecycle
- event system
- module loading
- storage routing
- service discovery

Kernel harus kecil.

Kernel tidak boleh mengetahui business logic.

---

# SERVICE MODEL

Service adalah capability.

Capability dapat:

- dipasang
- dilepas
- diganti
- ditingkatkan

tanpa mempengaruhi kernel.

---

# DATABASE MODEL

Database adalah penyimpanan.

Database bukan identitas.

Supabase dapat diganti.

PostgreSQL dapat diganti.

SQLite dapat diganti.

Identitas Mamet tetap sama.

---

# INFRASTRUCTURE MODEL

Github adalah gudang code.

Vercel adalah tempat menjalankan frontend.

Supabase adalah tempat menyimpan data.

OpenRouter adalah pasar CPU AI.

Tidak ada satupun dari mereka adalah Mamet.
