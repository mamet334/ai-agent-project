## 📌 RINGKASAN PROYEK
Proyek ini adalah platform AI Agent canggih bertenaga Google Gemini API, Groq Cloud API, dan OpenRouter yang dideploy sepenuhnya di Vercel secara gratis.

## 🌐 DATA DEPLOYMENT & INFRASTRUKTUR
- **GitHub Repository**: `https://github.com/mamet334/ai-agent-project.git`
- **Frontend Vercel**: `https://ai-agent-project-2a9h.vercel.app` (Vite, TailwindCSS)
- **Backend Vercel**: `https://ai-agent-project-eight.vercel.app` (Express.js)
- **Database & Auth**: Supabase (`chats` table dengan Row Level Security)
- **Sub-Agent Search**: Menggunakan `googlethis` sebagai fallback gratis jika Gemini API terkena rate-limit.

## ✅ FITUR YANG SUDAH SELESAI
1. **Multi-Agent Orchestrator (Kepala Agent)**: Memecah tugas untuk sub-agent (Researcher, Coder, Communicator).
2. **User Authentication (Supabase)**: Form Login/Register dan integrasi RLS (Row Level Security).
3. **Database Integration (Supabase)**: Sinkronisasi riwayat chat *real-time* ke cloud, persisten antar perangkat.
4. **Graceful Fallbacks**: Penanganan error canggih jika API key OpenRouter kosong, atau kuota Gemini habis.
5. **Fitur RAG (Document Upload)**: Upload dan ekstraksi teks dari PDF, DOCX, TXT, CSV tanpa batas memori Vercel.
6. **Vision Agent (Analisis Gambar)**: Ekstraksi gambar dan kompresi otomatis untuk dianalisis oleh AI.
7. **Agent Riset & Penulis Kode**: Sub-agent khusus yang siap mencari informasi dari internet dan mengeksekusi kode secara dinamis.

8. **Web Scraper Agent**: Agen khusus untuk mengekstrak dan membaca artikel/teks langsung dari URL spesifik yang diberikan user.
9. **Streaming Response (Typewriter)**: Efek visual mengetik kata demi kata secara *real-time* agar terasa hidup dan cepat seperti ChatGPT.
