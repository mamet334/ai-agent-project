## 📌 RINGKASAN PROYEK
Proyek ini adalah platform AI Agent canggih bertenaga Google Gemini API, Groq Cloud API, dan OpenRouter yang dideploy sepenuhnya di Vercel secara gratis.

## 🌐 DATA DEPLOYMENT & INFRASTRUKTUR
- **GitHub Repository**: `https://github.com/mamet334/ai-agent-project.git`
- **Frontend Vercel**: `https://ai-agent-project-2a9h.vercel.app` (Vite, TailwindCSS)
- **Backend Vercel**: `https://ai-agent-project-eight.vercel.app` (Express.js)
- **Database & Auth**: Supabase (`chats` table dengan Row Level Security)
- **Sub-Agent Search**: Menggunakan `googlethis` sebagai fallback gratis jika Gemini API terkena rate-limit.

## ✅ FITUR YANG SUDAH SELESAI
1. **Multi-Agent Orchestrator (Kepala Agent)**: Memecah tugas untuk sub-agent (Researcher, Coder, Communicator).
2. **User Authentication (Supabase)**: Form Login/Register dan integrasi RLS (Row Level Security).
3. **Database Integration (Supabase)**: Sinkronisasi riwayat chat *real-time* ke cloud, persisten antar perangkat.
4. **Graceful Fallbacks**: Penanganan error canggih jika API key OpenRouter kosong, atau kuota Gemini habis (fallback ke Groq + GoogleThis).

## 🚀 ROADMAP PENGEMBANGAN SELANJUTNYA (VISI "MEDVI")
Kita akan mengerjakan fitur-fitur mutakhir berikut secara bertahap:
1. **Fitur RAG (Document Upload)**: Menambahkan tombol attachment untuk mengunggah PDF/Word/Excel agar AI bisa membaca data internal user.
2. **Vision Agent (Analisis Gambar)**: Kemampuan untuk mengirim dan menganalisis gambar/foto di dalam chat menggunakan model Vision (Gemini 2.5 Flash/Pro).
3. **Web Scraper Agent**: Agen khusus untuk mengekstrak dan membaca artikel/teks langsung dari URL spesifik yang diberikan user.
4. **Streaming Response**: Menampilkan ketikan AI kata demi kata secara *real-time* agar terasa lebih hidup dan cepat.

Bacalah file ini, dan langsung tanyakan kepada user fitur mana dari "Roadmap Visi Medvi" di atas yang akan kita eksekusi sekarang!
