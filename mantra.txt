## 📌 RINGKASAN PROYEK
Proyek ini adalah platform AI Agent bertenaga Google Gemini API, Groq Cloud API, dan OpenRouter yang dideploy sepenuhnya di Vercel secara gratis tanpa kartu kredit.

## 🌐 DATA DEPLOYMENT
- **GitHub Repository**: `https://github.com/mamet334/ai-agent-project.git`
- **Frontend Vercel**: `https://ai-agent-project-2a9h.vercel.app`
  - *Pengaturan Vercel*: Preset Vite, Root Directory: `frontend`
  - *Environment Variable*: `VITE_API_URL = https://ai-agent-project-eight.vercel.app`
- **Backend Vercel**: `https://ai-agent-project-eight.vercel.app`
  - *Pengaturan Vercel*: Preset Other, Root Directory: `backend`
  - *Environment Variable*: `GEMINI_API_KEY`, `GROQ_API_KEY` (Telah Dikonfigurasi), `OPENROUTER_API_KEY` (Optional), `SLACK_WEBHOOK_URL` (Optional).

## 📂 FITUR UTAMA & FILE KUNCI
1. **`frontend/src/components/AIAgent.jsx`**:
   - UI chat utama menggunakan Tailwind CSS.
   - **Model Selector**: Dropdown pemilihan model AI (termasuk "Kepala Agent", Gemini 2.5 Flash, Gemini 2.5 Pro, Llama 3.3 70B, Llama 3.1 8B, Llama 3 8B OpenRouter, DeepSeek R1 OpenRouter) dengan penyimpanan otomatis di `localStorage`.
   - **Citations, Tool Logs, & Subagent Pipeline**: Menampilkan tautan sumber referensi dari pencarian Google, kotak log eksekusi kode/API, serta **alur kerja pipeline sub-agent** secara visual di bawah balon pesan.
   - **Multi-thread Chat Drawer**: Drawer sidebar responsif untuk membuat dan mengelola riwayat chat.
2. **`backend/server.js`**:
   - Express server routing untuk melayani API call dari frontend.
   - **Kepala Agent (Multi-Agent Orchestrator)**: Jika dipilih, backend menggunakan model koordinator untuk membuat plan sekuensial, kemudian mengeksekusi sub-agent khusus (researcher, coder, communicator) secara berurutan dan mengembalikan log eksekusinya ke frontend.
   - **Gemini Function Calling (Tool Use)**: 
     - `execute_javascript`: Mengeksekusi script JS secara nyata di runtime Node sandbox.
     - `make_api_call`: Mengirim HTTP request nyata ke API luar menggunakan Axios.
     - `post_to_slack`: Mengirim webhook Slack jika URL diset.
     - `google_search`: Menggunakan pencarian Google grounding bawaan Gemini.
   - **OpenRouter Proxy**: Mengirim chat ke OpenRouter API jika model OpenRouter dipilih.
   - **Groq Cloud API**: Mengirim chat ke Groq API menggunakan `GROQ_API_KEY` jika model Groq Llama dipilih.
