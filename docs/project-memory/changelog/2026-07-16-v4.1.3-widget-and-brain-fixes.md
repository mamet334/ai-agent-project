# Changelog - v4.1.3 (2026-07-16)

## Features & UI/UX Improvements
- **Widget Manager Refactor**: Functional header controls for widgets (MAEF Monitor, etc.).
  - `Minus`: Collapse/Expand widget content
  - `Maximize`: Fullscreen overlay mode for widget focus
  - `X`: Remove widget from active zone
  - `Drag Grip`: Relocated inside the widget header for intuitive repositioning.
- **Brain Cluster Alignment**: Realigned the central visual nomenclature of the Mamet Brain map to strictly adhere to the `06_MEMORY_SYSTEM.md` MAEF Kernel architecture.
  - Renamed `SUPABASE CORE` to `MAEF KERNEL`
  - Renamed Infrastructure nodes to Cognitive equivalents (`EDGE FUNCTIONS` -> `CAPABILITY PORTS`, `REALTIME` -> `EVENT BUS`, etc.)

## Fixes
- Fixed non-responsive buttons on floating widgets due to missing click handlers.
- Passed down `onClose` properties securely through `WorkbenchZone` directly to `WidgetHost`.
