## 🚀 1. Dashboard UX Restructuring (MAEF + MUS + ADR-008 Compliant)
**Konteks:** Sesuai arahan spesifikasi desain, *Home Dashboard* bukanlah *Workspace* maupun *Conversation Page*. Dashboard harus menjadi "Control Center" yang menampilkan status sistem seketika OS dinyalakan, dan *Conversation Engine* harus didekopel dari entri utama.
- **Implementasi:**
  - Membuat komponen `Sidebar.jsx` independen sebagai *Global Sidebar* (menggantikan widget navigasi *hardcode*).
  - Merombak hierarki `OSDesktopShell.jsx` agar merender *Sidebar*, *ActivityBar*, dan *ApplicationContainer* secara sejajar.
  - Memodifikasi `ApplicationContainer.jsx` dengan membungkus aplikasi *lazy-load* (seperti `HomeDashboard` dan `ConversationEngine`) menggunakan `React.Suspense`. Aplikasi tidak pernah di-*unmount* saat tidak aktif (hanya di-*hidden* lewat CSS class) untuk mempertahankan *state* memori percakapan, sesuai dengan spesifikasi ekosistem OS.

## 🛠️ 2. Resolusi Kritis Pipeline Build (Vite & Vercel)
**Konteks:** Perubahan desain awal tidak terefleksi pada *Live Site* Vercel karena *build pipeline* terus mengalami _crash_ secara senyap.
- **Fix JSX Syntax di File Standar:** File `Kernel.js` dan `AppRegistry.js` sebelumnya mengekspor sintaks JSX (`<Component />`) menggunakan ekstensi `.js`. Plugin *rollup-obfuscator* menolak mengkompilasinya.
  - *Solusi:* Kode direfaktor murni menjadi pemanggilan fungsional `React.createElement(...)` tanpa mengubah ekstensi file.
- **Fix Dynamic Module Paths:** Pemanggilan *lazy import* di `AppRegistry.js` (berlokasi di `src/core/application/`) menggunakan relasi path yang salah (`import('../components/...')`).
  - *Solusi:* Diperbaiki menjadi `import('../../components/...')` sehingga *Rollup bundler* tidak lagi tersesat.
- **Fix Obfuscator Dynamic Import Corruption:** Pada Vercel, *dashboard widget* terus melempar error `TypeError: error loading dynamically imported module` yang menyebabkan URL _widget_ mengarah ke alamat mentah/sumbernya dan berujung 404.
  - *RCA:* *Rollup-obfuscator* mengubah *string path* pada *dynamic import* menjadi array heksadesimal teracak. Akibatnya, _Rollup_ gagal melakukan analisis statis sehingga _chunk file_ (.js terpisah) tidak pernah dibuat.
  - *Solusi:* Menambahkan `src/core/application/AppRegistry.js` ke daftar pengecualian (`exclude`) *obfuscator* di `vite.config.js`. File *chunk* berhasil dibentuk ulang dan _live deployment_ berjalan lancar.

## ⚙️ 3. Arsitektur Kernel Boot Sequence & Dependency Guards (ADR-008)
**Konteks:** Terjadi *Kernel Panic* dengan pesan `ServiceManager: Service not found: MetadataService` saat mem-booting *Mamet OS*.
- **RCA:** Sistem *Booting* mengalami pelanggaran rantai dependensi. *WidgetRegistry* memuat modul pada **Fase 1**, namun modul-modul tersebut membutuhkan referensi dari `MetadataService` yang pada arsitektur lama baru diinisialisasi pada **Fase 9**.
- **Solusi Arsitektural (Kernel.js Restructuring):**
  - **Fase 1:** Mengangkat `MetadataService` untuk diregistrasi paling pertama segera setelah *ServiceManager* siap, menjadikannya "*Source of Truth*" sedini mungkin.
  - **Fase 9:** Mendaftarkan manajer menengah: `ApplicationManager`, `WorkspaceManager`, dan `NavigationService`. Ditambahkan *Dependency Assertion Guard* ketat yang memastikan `MetadataService` eksis; bila absen, *boot* di-*abort* secara deterministik.
  - **Fase 10:** Menurunkan `WidgetRegistry` dan pemanggilan `_registerDefaultWidgets()` ke tahap prafinal (sebelum UI *Dashboard* dirender). Fase ini diamankan oleh 4 lapis validasi dependensi untuk mencegah kecelakaan pemuatan di masa depan.
  - Mengimplementasikan `throw new Error()` dengan *stack trace* arsitektural yang jelas alih-alih `return` (silent fail).

## 🪲 4. Perbaikan Komponen UI & Kesalahan Rendering
Beberapa *error* lanjutan berhasil ditelusuri dan diperbaiki pasca-stabilisasi proses *boot*:
- **AppShell React Error Boundary Crash**
  - *Error:* `Element type is invalid: expected a string or a class/function but got: object.`
  - *RCA:* Pembungkus komponen pada `AppRegistry.js` mengekspor *React Element* mentah ke prop `mainPanel` yang kemudian dikonsumsi secara keliru oleh `<AppShell>` sebagai komponen fungsional (*functional component instantiation*).
  - *Solusi:* Mengonversi prop `mainPanel` menjadi *arrow function component* `(props) => <Suspense>...</Suspense>`.
- **CurrentActivityWidget Crash**
  - *Error:* UI hampir *crash* saat widget memanggil `serviceManager.get('Kernel')`.
  - *RCA:* `Kernel` adalah akar eksekusi statis, bukan entitas _service_ dinamis di dalam *ServiceManager*.
  - *Solusi:* Memanggil *state* Kernel langsung dari *import* modul sumber (`import { kernel }`).
- **Sidebar Kosong & Phantom Error**
  - *Error:* Sub-menu *Sidebar* tidak terisi. *Log Console* menampilkan *soft crash* `Widget Not Found: widget:workspace-nav`.
  - *RCA:* *Metadata* sub-menu di `navigation.json` tidak mendefinisikan properti `type: "item"`, sehingga *logic rendering Sidebar* secara buta mengabaikannya. Selain itu, konfigurasi lama `workspace.json` masih mencari widget lama yang sudah dipensiunkan oleh *Global Sidebar*.
  - *Solusi:* Memodifikasi kriteria filter di `Sidebar.jsx` menjadi `node.type === 'item' || node.appId`, dan menghapus `widget:workspace-nav` dari *default layout* konfigurasi *workspace*.
