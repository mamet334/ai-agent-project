# Changelog - v4.1.2 (2026-07-16)

## Features & Improvements
- **Responsive UI Update**: Full mobile and tablet support implemented across Mamet OS ecosystem.
- **OSDesktopShell**: Implemented intelligent breakpoints for switching between fixed sidebar (desktop) and bottom navigation bar (mobile).
- **Sidebar Navigation**: Converted left sidebar into an interactive drawer for mobile views, retaining the clean icon-only structure for desktop.
- **Settings Screen**: Refactored grid layouts into stack patterns on smaller viewports.
- **AIAgent Layout**: The Chat History panel is now a collapsible overlay on mobile, preventing overlap with the chat stream.
- **Global CSS Adjustments**: Implemented native mobile feel with `viewport-fit=cover` for safe areas (iPhone notch support), smoother scrolling, customized scrollbars, and standard 44px minimum touch targets.

## Fixes
- Fixed hardcoded margins (`ml-16`) in `ApplicationContainer` to support variable widths based on screen size.
- Improved index.html tags for Progressive Web App (PWA) installation.

*Release triggered via GitHub Actions.*
