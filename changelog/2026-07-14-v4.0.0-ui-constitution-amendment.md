# Mamet AI v4.0.0 - Layout Engine & UI Constitution Amendment
**Date:** 2026-07-14

## Overview
This release focuses on hardening the Mamet OS Desktop UI layout engine to prevent "Scroll-to-Focus" layout shift bugs, and restructuring the application navigation according to the newly established UI Constitution Amendment.

## UI Constitution Amendment
A strict architectural boundary was established for UI navigation elements:
- **Global Navigation (Sidebar):** The Sidebar (`Sidebar.jsx`) is now strictly reserved for Global Navigation (Mode Switching like Assistant/Engineer/Lite, Knowledge, Settings).
- **Session Navigation (ConversationEngine):** The `+` (New Chat) button was removed from the Global Sidebar and relocated to `ConversationEngine.jsx`.
- **Session Toolbar:** The `☰` (History Toggle) and `+` (New Chat) buttons are now grouped together in a dedicated `SessionToolbar` layer inside `ConversationEngine`. This ensures that session-specific history and new conversation triggers are fully encapsulated within the active mode, matching the architectural design of tools like Cursor, Claude Desktop, and ChatGPT.

## Layout Engine & Scroll Isolation (Native Desktop Feel)
The system was audited to find the root cause of an issue where the top-left layout (including the ☰ button) would shift upward out of the viewport.

1. **CSS Grid Clamping (`AppShell.jsx`)**: 
   - Replaced `gridTemplateRows: '1fr'` with `minmax(0, 1fr)`.
   - In CSS Grid, `1fr` allows auto-expansion if the content exceeds the container height. Using `minmax(0, 1fr)` enforces strict clamping, ensuring the grid row never exceeds 100vh.

2. **Flexbox Height Clamping (`ConversationEngine.jsx`)**:
   - Added `min-w-0 min-h-0` to all flex column wrappers (`Area Chat Utama`, `MessageList`, and root container).
   - This prevents child elements from overriding the parent's height constraints due to Flexbox's default `min-height: auto` behavior.

3. **Global Scroll Lock (`index.css`)**:
   - Added `overflow: hidden; height: 100%;` to `html, body` to definitively prevent the native browser "Scroll-to-Focus" behavior, which attempts to scroll the entire document when an off-screen or borderline element receives focus.

4. **SessionToolbar Restructure (`ConversationEngine.jsx`)**:
   - Discovered that absolute positioned `Atmospheric Background Glow` elements (`-bottom-32`) were artificially expanding the `scrollHeight` of the chat container. 
   - When the component mounted, the `scrollIntoView()` call intended for the message list forced the container to scroll up by 128px, pushing the Session Toolbar off-screen.
   - **Fix:** Restructured the DOM by extracting the `SessionToolbar` out of the inner scrolling wrapper. The toolbar now resides in an outer wrapper (`Area Chat Utama`) that does not have `overflow-hidden`, completely isolating it from any internal scroll shifts caused by glows or message lists.
