# Changelog & Root Cause Analysis (RCA) - 2026-07-05

## 1. Dashboard UI Restructuring & Global Sidebar
- **Objective:** Mengimplementasikan "Home Dashboard" sebagai *Control Center* (Main View) sesuai panduan **MUS (Mamet UI Specification)**.
- **Perubahan:**
  - `OSDesktopShell.jsx` direstrukturisasi untuk menggunakan *Global Sidebar* independen (`Sidebar.jsx`).
  - `ApplicationContainer.jsx` ditambahkan `React.Suspense` untuk membungkus modul aplikasi secara *lazy load* tanpa menyebabkan *runtime crash*.

## 2. Fix: JSX Syntax Error pada Vercel Build (Vite)
- **Error:** *Build failed* dengan `Unexpected token` saat mencoba mem- *parsing* `Kernel.js` dan `AppRegistry.js`.
- **RCA:** Ekstensi file adalah `.js`, namun di dalamnya digunakan sintaks JSX (`<AppShell />`, `<RenderComp />`). Plugin *rollup-obfuscator* tidak mendukung *parsing* JSX di dalam file berekstensi `.js`.
- **Resolusi:** Mengubah penulisan JSX pada `Kernel.js` dan `AppRegistry.js` sepenuhnya menjadi pemanggilan `React.createElement` murni, tanpa mengubah ekstensi file.

## 3. Fix: AppRegistry Path Resolution Error
- **Error:** `Could not resolve "../components/agent-forge/AgentForge" from "src/core/application/AppRegistry.js"`.
- **RCA:** Letak `AppRegistry.js` dipindahkan ke `src/core/application/`, namun *path* modul (seperti `../components/...`) belum diperbarui, yang mengarah ke `src/core/components` yang tidak pernah ada. 
- **Resolusi:** Mengubah seluruh *relative path import* menjadi `../../components/...`.

## 4. Fix: Kernel Boot Sequence Violation (ADR-008 Compliant)
- **Error:** `ServiceManager: Service not found: MetadataService`.
- **RCA:** Terjadi inversi dependensi (*dependency inversion*) pada fase *booting*. `WidgetRegistry` mencoba membaca _Metadata_ di **Fase 1**, sementara `MetadataService` baru diregistrasi di **Fase 9**. Akibatnya seluruh widget dibatalkan (*silent fail*).
- **Resolusi (Arsitektural):**
  - **Fase 1:** Menginisiasi dan mendaftarkan `MetadataService` segera setelah *ServiceManager* siap (sebagai fondasi seluruh ekosistem).
  - **Fase 9:** `ApplicationManager`, `WorkspaceManager`, dan `NavigationService` diregistrasi dengan menambahkan instruksi **Dependency Assertion** terhadap `MetadataService`.
  - **Fase 10:** `WidgetRegistry` dan pemanggilan `_registerDefaultWidgets()` diletakkan paling terakhir sebelum *Dashboard* menyala, serta dijaga dengan proteksi *Dependency Guards* (4 lapis).

## 5. Fix: React Error Boundary Panic (AppShell)
- **Error:** `Element type is invalid: expected a string or a class/function but got: object.`
- **RCA:** Pada `AppRegistry.js`, *wrapper* modul `GenericAppWrapper` melemparkan prop `mainPanel` sebagai instansi statis *React Element* (Object), padahal `AppShell` mencoba membacanya sebagai komponen `<MainPanelComponent />` (*Function Component*).
- **Resolusi:** Membungkus prop `mainPanel` di `AppRegistry.js` menjadi fungsi anonim yang sah: `(props) => <Suspense>...</Suspense>`.

## 6. Fix: CurrentActivityWidget Crash
- **Error:** Terjadi *Kernel Panic* dengan pesan `Service not found: Kernel`.
- **RCA:** *Widget* mencoba memanggil *Kernel* lewat `serviceManager.get('Kernel')`. *Kernel* bukanlah sebuah *service*, melainkan *singleton core* independen.
- **Resolusi:** Mengimpor instansi `kernel` langsung secara absolut melalui `import { kernel } from '../../../core/runtime/Kernel'`.

## 7. Fix: Sidebar Kosong & Widget Not Found
- **Error:** `Sidebar` gagal merender sub-menu _(Assistant, Lite, Engineer, Knowledge Base)_ dan log konsol mencatat error *soft crash* `Widget Not Found: widget:workspace-nav`.
- **RCA:**
  1. *Metadata* di `navigation.json` menyusun sub-menu tanpa keterangan `type: "item"`, sehingga secara tak sengaja ditolak oleh mekanisme filter `Sidebar.jsx`.
  2. Modul `widget:workspace-nav` dipanggil oleh _default layout_ `ws-owner` di `workspace.json`, padahal komponen tersebut sudah dipensiunkan/diganti *Global Sidebar*.
- **Resolusi:** 
  1. Memperbarui `Sidebar.jsx` agar mengevaluasi sub-menu asalkan ia memuat kunci `appId` (`node.type === 'item' || node.appId`).
  2. Menghapus referensi `widget:workspace-nav` secara permanen dari konfigurasi `workspace.json`.

## 8. Fix: Vercel Production Dynamic Import 404
- **Error:** `TypeError: error loading dynamically imported module: https://.../components/dashboard/widgets/SystemStatusWidget`.
- **RCA:** Ini merupakan konsekuensi pasca-build dari `rollup-obfuscator`. Ketika file `AppRegistry.js` diobfuskasi, *string path* pada *dynamic import* berubah menjadi panggilan *hex string array* (`import(_0x123abc(0x1a))`). Karena tidak ada _string_ yang nyata, *bundler* Rollup gagal menganalisis modul mana yang harus dijadikan _chunk_, dan malah membiarkan URL asli (seperti *localhost* / *dev server*) masuk ke *production* Vercel (sehingga berujung 404).
- **Resolusi:** Memasukkan `src/core/application/AppRegistry.js` ke daftar pengecualian (exclude) plugin *rollup-obfuscator* di dalam `vite.config.js`.
