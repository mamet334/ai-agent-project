#### **3. Fungsi `handleSend()` — Simplified Logic**
```javascript
const handleSend = async () => {
  if (!input.trim()) return;
  const userMsg = { role: 'user', content: input };
  updateMessages(prev => [...prev, userMsg]);
  const currentInput = input;
  setInput('');
  setLoading(true);

  try {
    // Build tools array sesuai mode yang aktif
    let tools = [];
    if (activeModes.rag) tools.push('rag_search');
    if (activeModes.websearch) tools.push('web_search');
    if (activeModes.research) tools.push('deep_research');

    // Default jika tidak ada tools aktif
    if (tools.length === 0) tools = ['rag_search', 'web_search'];

    // Build chat history untuk context
    const chatHistory = messages.map(m => ({
      role: m.role,
      content: m.content
    }));

    // Kumpulkan BYOK keys
    const byokKeys = {
      'x-byok-gemini': localStorage.getItem('x-byok-gemini') || '',
      'x-byok-groq': localStorage.getItem('x-byok-groq') || '',
      'x-byok-openai': localStorage.getItem('x-byok-openai') || '',
      'x-byok-openrouter': localStorage.getItem('x-byok-openrouter') || ''
    };

    // PANGGIL AGENT LANGSUNG (SIMPLE)
    const response = await callAgentSimple(
      currentInput,
      tools,
      session.user.id,
      session.user.email.split('@')[0],
      chatHistory,
      activeModes.rag,
      byokKeys
    );

    // Tambah placeholder untuk assistant message
    updateMessages(prev => [...prev, { role: 'assistant', content: '' }]);

    // Parse SSE stream dan update real-time
    const contentType = response.headers.get('Content-Type') || '';
    
    if (contentType.includes('text/event-stream')) {
      // Stream SSE
      await parseSSEStream(response, (chunk, fullContent) => {
        updateMessages(prev => {
          const newArr = [...prev];
          newArr[newArr.length - 1].content = fullContent;
          return newArr;
        });
      });
    } else if (contentType.includes('application/json')) {
      // Fallback JSON
      const data = await response.json();
      const textContent = data.content || data.text || data.message || JSON.stringify(data);
      updateMessages(prev => {
        const newArr = [...prev];
        newArr[newArr.length - 1].content = textContent;
        return newArr;
      });
    } else {
      throw new Error('Unexpected response format');
    }
  } catch(err) {
    updateMessages(prev => [...prev, { role: 'assistant', content: `❌ Error: ${err.message}` }]);
  } finally {
    setLoading(false);
  }
};
```

## Kesimpulan

✅ Ya — proyek ini sudah memiliki implementasi `router cerdas` di index.ts.

### Apa yang sudah ada

1. `runLLM()`
   - Memilih provider pertama berdasarkan `model` user:
     - `gpt*` → OpenAI
     - `openrouter*` → OpenRouter
     - `groq/*` → Groq
   - Jika tidak ada model khusus, memakai:
     - Gemini multi-key + retry
     - lalu fallback ke OpenRouter
     - lalu fallback ke Groq

2. `runCoordinatorLLM()`
   - Router lapis ringan / traffic-light:
     - `preferFast && GROQ_API_KEY` → Groq untuk tugas cepat
     - Gemini utama
     - OpenRouter jika Gemini gagal
     - Groq jika masih perlu

3. `Intent Router` di request utama
   - Menganalisis pesan user untuk memilih antara:
     - `CHAT_BIASA` → jawab langsung tanpa sub-agent
     - `BUTUH_AGENT` → panggil sub-agent
   - Menggunakan prompt `runCoordinatorLLM(..., true)` untuk klasifikasi intent

4. `Traffic Light Router` untuk sub-agent
   - Jika sub-agent adalah `coder` / `debate` → pakai `openrouter-deepseek-r1`
   - Jika sub-agent ringan seperti `scraper`, `memory_manager`, `communicator`, `youtube_analyst`, `file_analyzer` → pakai Groq
   - Lainnya → Gemini

5. Fallback otomatis
   - OpenAI streaming error → fallback ke Groq
   - OpenRouter stream error → fallback ke Groq
   - Gemini stream 429 → fallback ke OpenRouter / Groq

### Jadi, ringkasnya

- `agent-process` memang punya routing cerdas
- routing berbasis:
  - `model` yang diminta
  - jenis request / intent
  - tipe sub-agent
  - ketersediaan dan error provider
- bukan hanya satu mekanisme tunggal, tetapi beberapa lapis router + fallback

> Jika yang Anda maksud adalah “otomatis memilih model berdasarkan kompleksitas prompt secara adaptif”, saat ini sudah ada bentuk itu lewat rule-based intent/sub-agent routing dan fallback, bukan lewat scoring model kompleksitas yang terpisah.
