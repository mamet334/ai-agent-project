⚙️ 2. THE REAL INTELLIGENCE PIPELINE (DETERMINISTIC)
============================================================

Sistem memproses setiap HTTP request dalam langkah linear berikut:

1. [GATEKEEPER LAYER]
   - Auth Binding Layer: Ekstrak JWT aktif, tolak request tanpa token valid (401), menimpa `userId` dari payload dengan Server Identity (AUTH_USER_ID) untuk mencegah IDOR.
   - Execution Policy Layer: Menghitung skor risiko untuk memblokir prompt injection atau membatasi akses eksekusi.
   - Circuit Breaker: Memeriksa RPC `check_daily_quota` di Supabase.

2. [STATELESS SESSION]
   - Edge Function TIDAK memiliki in-memory short-term memory (RAM state).
   - Frontend mengirimkan riwayat percakapan (`history`) mentah-mentah ke backend di setiap request.

3. [DATA RETRIEVAL LAYER]
   - Dikontrol oleh Unified Execution Context (mengatur batas RAG TopK dan Threshold).
   - Memory Engine: Menjalankan `retrieveMemories()` secara eksklusif menggunakan `AUTH_USER_ID`.
   - RAG Fetcher: Menjalankan RPC `match_documents` secara eksklusif menggunakan `AUTH_USER_ID`.

4. [CONTEXT FUSION LAYER] (`context_fusion.ts`)
   - Structured Reasoning Layer: Mengubah hasil Memory dan RAG menjadi objek JSON hierarkis terstruktur (Tahap 1).
   - Prompt Serialization: Merangkai objek konteks secara deterministik ke dalam string dengan blok delimiter tegas untuk mencegah tumpang tindih data RAG vs Memory (Tahap 2).

5. [SUB-AGENT / PLUGIN ROUTER]
   - Jika payload berisi `tools`, memanggil spesifik fungsi eksternal (Web Search, YouTube Analyst).

6. [LLM CASCADE ORCHESTRATOR] (`getStreamResponse`)
   - Strict Model Routing: Mencoba Gemini.
   - Invalid Model Guard: Jika HTTP 404/400 → lempar FATAL_CLIENT_ERROR dan putus koneksi (Fail-Fast).
   - Fallback (Hanya 429/500): Cascade fallback ke Groq → OpenRouter.

7. [BACKGROUND TASKS] (`safeFireAndTrack`)
   - Logging API Usage.
   - Menulis memori baru secara asinkron via `processMemoryWriteQueue` (Memory Write Worker).

============================================================

- Belum ada vector/embedding semantic intelligence murni di dalam layer penyusunan memori itu sendiri.
