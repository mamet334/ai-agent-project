============================================================
🏗️ 1. ARSITEKTUR MEMORI
============================================================

1) LONG-TERM MEMORY (SUPABASE)
- Database persisten (mamet_memory)
- Menyimpan: key / value memory, semantic_identity, confidence, truth_score
- Supabase = SINGLE SOURCE OF TRUTH

2) SHORT-TERM MEMORY (SESSION RAM)
- In-memory FIFO buffer (±10 chat terakhir)
- Tidak disimpan ke database
- Fungsi: konteks percakapan cepat & anti-amnesia jangka pendek

3) BEHAVIOR MEMORY ENGINE
- Heuristic user profiling real-time (formal/casual, kecepatan respon, pola pikir)
- Decay factor ~0.98 agar adaptif. Tidak menggunakan database.

============================================================
🔁 2. INTELLIGENCE PIPELINE (CURRENT FINAL TRUTH)
============================================================

User Input
  ↓
Semantic Bridge (normalisasi + keyword heuristic) & Intent Preprocessor
  ↓
Memory Engine (Supabase READ ONLY - fetch data mentah)
  ↓
Memory Governor (FILTER ONLY - menyaring noise & ranking relevansi)
  ↓
Optimal Context Budgeting / OCB (COMPRESSION ONLY - optimasi budget token)
  ↓
Decision Engine (SINGLE SOURCE OF TRUTH / FINAL AUTHORITY - final orchestrator)
  ↓
LLM (ChatGPT → hanya language renderer)

*No other layer is allowed to exist in execution path.*

============================================================
🧩 3. MODULE RESPONSIBILITY CLARIFICATION
============================================================

- Memory Engine: ONLY fetch data from Supabase. NO scoring, NO filtering logic.
- Memory Governor: ONLY filter and rank memory relevance. NO final decision authority. NO prompt building.
- OCB: ONLY compress and optimize token usage. NO semantic decision making.
- Decision Engine: ONLY FINAL AUTHORITY. Builds final prompt, merges context + behavior + memory, produces final LLM input.

🧠 5. DESIGN PRINCIPLES & HARD CONSTRAINTS
============================================================

- SINGLE DECISION AUTHORITY MODEL: Decision Engine adalah pemegang keputusan tunggal mutlak.
- DETERMINISTIC LINEAR PIPELINE: Tidak ada recursion, loop, atau multiple orchestrators.
- NO OVERLAPPING ENGINES: Tidak ada duplicate scoring systems atau parallel decision systems.
- NO HIDDEN LOGIC: Tidak ada hidden reasoning pipelines di luar Decision Engine.
- NO HALLUCINATION: LLM hanya sebagai response renderer, bukan pengambil keputusan.
- REACTIVATION BAN: Jangan mengaktifkan ulang modul legacy ke dalam jalur eksekusi utama.
- NO NEW COGNITIVE LAYERS: Dilarang menambah lapisan kognitif baru di luar pipeline ini.
